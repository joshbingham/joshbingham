About

I’m a frontend and full-stack developer based in Worthing with an MEng Aerospace Engineering background. I enjoy building practical software that turns complex workflows and information-heavy problems into clearer experiences.

My recent work spans React and TypeScript interfaces, Node.js and Express backends, REST APIs, PostgreSQL, automated testing and commercial freelance development. I use GitHub issues, branches, pull requests and regular feedback to keep development organised and maintainable.

A clear, organised build process

Clear scope. I break a brief or problem into practical features, screens and technical steps.

Iterative build. I build in manageable increments and use feedback to refine the direction early.

Organised delivery. I use GitHub issues, branches and pull requests to keep changes traceable and reviewable.
